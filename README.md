# algorithmStudy


### 스터디 진행 방식

- 진행 시간 : 1시간 30분(풀이 시간) + 30분 (로직 설명)
- 일시 :  매주 수요일 22시 (변동 가능)
- 디스코드 라이브에서 화면공유를 한 상태로 진행합니다.
- 격주로 문제 세 개를 지정하며 스터디 전까지 Git Issue를 발행합니다.
- 문제는 `프로그래머스`, `백준`, `리트코드`에서 가져옵니다.
- 1~2월간은 우선 프로그래머스로 선정

### 문제 선정 기준
